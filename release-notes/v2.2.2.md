# QYReader v2.2.2

2026-10-28

- **减少书架重复渲染**：书卡独立记忆化，切换大书库显示范围时，保留书卡跳过重复渲染，只更新新增或实际发生变化的书卡。
- **减少重复计算**：稳定卡片事件回调，缓存筛选结果 ID 与多选集合，保留筛选、跨显示范围多选、卡片菜单、拖拽排序和打开正文的操作。
- **沿用现有兼容配置**：保留此前用于减少透明窗口闪白的 Qt 合成路径、虚拟列表阈值与缓冲方式，保持现有主题、圆角及共享朗读状态。

本轮优化确认减少了重复渲染，但真实 Qt 滚动仍有长帧，未确认所有滚动方向均有性能提升，尚未达到全程零掉帧。最终源码的 360 次 Qt 窗口缓冲采样未检出内容缺失；该采样不能证明显示器逐帧不闪白。详细方法与限制见 `docs/scroll-performance-2026-10-28.md`。

源码功能回归覆盖筛选和空结果、窄窗口末尾、多选保持、拖拽排序及取消、卡片菜单和打开正文。安装向导、覆盖升级及真实扬声器听感未在本轮重新验收。

下载安装包 `QYReader-Setup-2.2.2.exe`，使用同一 Release 的 `SHA256SUMS.txt` 核对文件。升级前完全退出启远阅读；书架、进度、笔记、设置和已下载模型沿用现有数据格式。
