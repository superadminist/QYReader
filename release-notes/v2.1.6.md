# QYReader v2.1.6

- 悬浮窗新增全文朗读进度条，显示已读比例，与主界面的朗读位置保持同步。
- 在「设置 → 朗读与悬浮 → 悬浮朗读」中新增「允许拖动朗读进度」开关，默认关闭，修改后自动保存。
- 关闭开关时，进度条没有圆点，仅展示进度；开启时显示圆点，支持点击或拖动跳转。
- 拖动时预览百分比，松手后才跳转，并保持播放或暂停状态；取消拖动或中途关闭开关不会跳读。
- 进度条随原有操作栏一起在鼠标悬停时显示，适配小窗口，保留播放按钮、背景透明度和缩放操作。

下载 `QYReader-Setup-2.1.6.exe` 安装或覆盖升级。安装前请先完全退出正在运行的启远阅读；现有书架、阅读进度和设置保留。`SHA256SUMS.txt` 用于校验安装包。

本轮完成 Qt 浮窗两种模式、拖动预览与松手跳转、取消拖动、播放/暂停状态同步及小窗口布局验证。Qt 界面验证使用测试兼容渲染模式和模拟语音事件，未进行人工听音验收。
