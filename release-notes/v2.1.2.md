# QYReader v2.1.2

- 补齐夜间模式的播放栏、字号工具条、章节标题、目录、菜单和弹窗配色。
- 优化主窗口与悬浮窗缩放时的圆角裁剪，减少重复窗口状态更新；最大化还原、托盘恢复后同步布局与重绘。
- 内容库增加“最近阅读 / 自定义排序”切换。自定义模式支持跨行拖动、边缘自动滚动，排序重启后保留；搜索期间暂停拖动。
- 右键书籍卡片或点击“更多”，可选择“打开源文件位置”。源文件移动、删除或无法打开时显示明确提示。
- 导入文件默认打开上次确认选择的目录；取消选择不更新，目录失效时自动回退。

下载 `QYReader-Setup-2.1.2.exe` 安装或覆盖升级。安装前请先完全退出正在运行的启远阅读。

验证范围：源码测试和前端构建通过；100%、125%、150% 各完成 20 次诊断 Qt 窗口循环与尺寸检查。测试环境使用单进程 WebEngine 和程序化缩放，真实鼠标跟手、缩放中圆角、连续桌面画面及闪烁/半屏仍需实机验收；多屏、系统文件选择对话框和资源管理器实际选中文件未覆盖。
