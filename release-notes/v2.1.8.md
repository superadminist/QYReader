# QYReader v2.1.8

- 新增免费离线朗读 **Kokoro v1.0 INT8**：在设置中心下载或手动导入模型，可选择、试听晓北、晓妮、晓晓、晓伊、云健、云希、云夏和云扬。保留 Edge 在线朗读及 SAPI 本地朗读，主窗口与悬浮窗共用播放状态。
- 新增彩色划线笔记：选中文字后划线、添加或编辑备注；支持查看、跳转、删除，并导出包含书名、章节、摘录与备注的 Markdown / TXT，保留旧书签。
- 新增阅读与听书统计：今日、累计时长和按日期展示的热力图。总时长去除重叠；后台实际播放计听书，暂停、生成等待及试听不计听书，旧数据从零开始统计。
- 新增书架分类、多标签、内容类型和未读 / 阅读中 / 已读筛选。每本书一个分类、多个标签；进度达到 100% 自动标记已读，也可手动锁定状态。保留搜索、排序、导入及旧进度。
- 优化 Edge 冷却恢复和后续短句生成，减少重复联网请求与音色反复切换。新增界面沿用现有主题、控件和布局。

下载 `QYReader-Setup-2.1.8.exe` 安装或覆盖升级。安装前请完全退出启远阅读；现有书架、进度、笔记和设置保留。`SHA256SUMS.txt` 用于校验安装包。

**Kokoro 模型不包含在安装包内，也不是必需下载。** 不下载仍可正常阅读及使用 Edge / SAPI。官方 INT8 模型下载约 132.3 MB，展开后约 181.1 MiB，音频缓存另计；可选择其他磁盘，升级不需要重新下载。模型安装后合成、试听与朗读完全离线。

本轮源码自动化检查及界面验证通过，并完成 30 分钟连续播放检查。本机合成耗时约为音频时长的 1.85–2.42 倍，性能不足时会显示等待并保持所选音色；不同电脑表现可能不同。真实听感尚未人工验证，自动化检查不能替代实际试听。
