# QYReader v2.1.7

- 调整 Windows 透明窗口合成，处理内容库标题、导入按钮与书封同时闪白的问题。
- 默认使用 Qt 软件合成，保留主窗口与悬浮窗圆角、封面悬停动画和原有阅读功能。
- 保留驱动兼容渲染选项；启动配置不额外强制禁用 Chromium GPU，实际加速能力仍由 Qt 和驱动决定。

下载 `QYReader-Setup-2.1.7.exe` 安装或覆盖升级。安装前请先完全退出正在运行的启远阅读；现有书架、阅读进度和设置保留。`SHA256SUMS.txt` 用于校验安装包。

本机修改后完成 600 次原生窗口画面采样，未检出书封同时消失；主窗、悬浮窗圆角及最大化检查通过。自动测试未稳定复现用户录屏中的原始白屏，因此仍需实际使用确认；软件合成可能降低动画流畅度。
