# QYReader v2.2.0

2026-10-22

- **划线笔记改为选区附近的小浮条**，沿用现有主题、配色和控件风格，不再把大块按钮插入正文。
- **四色圆点，一键划线**：用颜色直接区分标记；“写笔记”打开轻量输入框，“朗读（从选区开始）”与笔记操作分隔显示。
- **直接点击已有划线管理笔记**：查看备注、修改颜色、编辑或删除，无需先去书签面板找对应条目。书签面板的定位与 Markdown / TXT 导出继续可用。
- **保存结果更明确**：保存成功后清除蓝色文字选区，显示实际划线与简短反馈；保存期间防止连续点击造成重复提交。
- **睡眠定时**：主窗播放条和悬浮窗操作栏提供 15 / 30 / 60 分钟、自定义 1–720 分钟、读完本章及取消定时。两个窗口显示同一倒计时；暂停朗读仍继续计时，到期保留当前位置并停止。章末定时在下一章发声前停止，切书或手动跳出目标章节时取消。
- **Edge 章节离线准备**：阅读工具栏的“准备离线听书”或“设置 → 离线听书”可选择当前章、后续若干章、自选章节或整本，固定音色和语速后后台准备。任务支持暂停、继续、校验、检查并补齐、取消及确认清理；取消任务保留音频，清理时保留共享和占用文件。
- **Kokoro 章节生成与持久保留**：在同一离线听书页面切换到 Kokoro，使用已安装模型本地生成。当前朗读和试听优先于后台任务；保留的章节不受临时缓存容量淘汰，需主动清理。模型或正文变化、缺片和磁盘不足会显示待校验或暂停状态，不把旧进度当作完成证明。
- **统一音色中心**：“设置 → 音色与模型”按 Edge、Kokoro 和系统音色分组，支持按名称、引擎或音色 ID 搜索、收藏与试听，并显示不可用原因。试听可取消或替换，不保存正式朗读音色、不推进书籍进度、不累计听书时长；试听后手动继续书籍朗读。
- **备份与恢复**：“设置 → 备份与恢复”可先估算大小，备份书架、可读取正文和源文件副本、进度、笔记、分类标签、收藏及统计，音频缓存与模型可选。恢复先校验文件并展示目标位置、缺失内容和替换范围，确认后按完整快照恢复，保留恢复前备份与回滚文件；书籍 ID 和笔记锚点保持，原始外部源文件不改动。
- **书架批量管理**：内容库点击“批量管理”进入多选，可全选当前筛选结果，批量设置或清除分类、添加或移除标签、修改阅读状态。筛选外的已选项目会显示数量；添加和移除标签保留其他标签，手动阅读状态可显式恢复自动判断。

笔记使用方式：在正文选中文字，点击浮条中的颜色圆点直接划线，或选择“写笔记”输入内容并保存。以后点击该处划线，即可查看和管理对应笔记。离线准备完成后，使用相同引擎、音色和语速朗读对应章节；重启后的任务需重新校验，SAPI 继续用于实时朗读。

本版本安装包名称为 `QYReader-Setup-2.2.0.exe`，`SHA256SUMS.txt` 用于校验安装包。升级前完全退出启远阅读；现有书架、进度、书签笔记、设置和已下载模型沿用现有数据格式，无需重新导入书籍或创建笔记。主窗与悬浮窗继续使用同一朗读状态。

本轮验证以隔离数据、后台状态和模拟播放为主；真实扬声器听感与安装版桌面操作尚未在本轮验收，生成速度仍取决于电脑和模型。
