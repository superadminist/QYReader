# QYReader v2.2.3

2026-10-30

- **阅读区右键菜单**：按段落、选中文字、已有划线和空白区域提供朗读、书签、复制、划线与笔记操作；支持定位当前朗读、切换目录、打开设置及进入悬浮阅读。
- **目录智能命名**：对自动生成的“第 N 节”等目录，从课程标题或开头摘要生成更易辨认的展示名；已有有效标题继续保留，续段显示“续1、续2”等标记。
- **长目录名省略**：名称超宽时单行省略，悬停查看全文；续段标记独立显示，窄目录下仍可辨认。
- **修复设置空白页**：阅读页的“更多设置”明确打开“朗读与悬浮”，修复点击事件被误当成设置分类导致的空白内容。

目录优化仅改变展示信息，保留原有章节分段、原始标题、正文、阅读进度、书签与缓存。已有书籍重新打开后即可应用，无需重新导入。

下载 `QYReader-Setup-2.2.3.exe`，使用本 Release 的 `SHA256SUMS.txt` 核对文件。升级前完全退出启远阅读；既有书架、进度、笔记、设置和已下载模型继续保留。

本轮验证使用隔离源码和自动化检查；安装向导、覆盖升级与 Qt 原生窗口点击操作未在本轮重新验收。
