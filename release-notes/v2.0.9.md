# QYReader v2.0.9 候选版

本版针对 2.0.8 仍出现的暂停跳句问题：本地系统语音在句边界已开始下一句，但 UI 尚未收到开始事件时，暂停按钮先保持刚才显示的句子；恢复后等系统语音实际重新开始才更新主面板和悬浮窗。

本地自动化复现了“点暂停后高亮跳到下一句”的事件顺序，并通过模拟系统语音回调验证了暂停、重读和两处文字状态。真实弱网与扬声器同步仍需在实际安装环境验证，因此这份说明对应本地候选包，尚未发布 GitHub Release。

候选安装包：`QYReader-Setup-2.0.9.exe`。

用户后续实测纯本地语音仍提前跳句；该候选包已由 2.0.10 候选包替代。
