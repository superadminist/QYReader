# QYReader v2.1.4

- 白天和护眼模式恢复浅灰白界面，以及原来的蓝紫色按钮和目录选中项。
- 护眼模式采用柔和中性底色，移除整窗和按钮的绿色配色；标题栏、侧栏、目录、阅读区与播放栏保持协调。
- 保留 v2.1.3 的实时圆角与透明窗口重绘修复。

下载 `QYReader-Setup-2.1.4.exe` 安装或覆盖升级。安装前请先完全退出正在运行的启远阅读；现有书架、阅读进度和设置保留。

本次配色修正已通过前端构建、55 项前端测试和真实 Qt 四种主题切换检查。实机预览确认护眼模式为浅灰白底色、蓝紫色按钮；窗口尺寸与圆角检查通过，未出现前端运行错误。本轮没有重新执行三档 DPI 各 20 轮窗口回归，沿用 v2.1.3 的窗口实现与此前验证。
