# QYReader v2.1.9

2026-10-13

- 新增 **Kokoro v1.0 普通版（FP32）** 可选模型，改善本机离线语音生成速度。保留 INT8 和原来的晓北、晓妮、晓晓、晓伊、云健、云希、云夏、云扬八种中文声线，不自动更换模型或音色。
- 选定离线音色后后台预热模型；当前朗读、跳转和试听优先于后续预取，已缓存音频直接可用，减少不必要的排队。
- 修复停止、跳转、取消试听和切换模型时旧生成任务影响新请求的问题，确保不同模型的请求与音频缓存隔离。
- 音频缓存改为增量计量，减少每句生成后的磁盘扫描；兼容 Windows 长缓存路径，写入失败时提供明确提示。

下载 `QYReader-Setup-2.1.9.exe` 安装或覆盖升级。安装前请完全退出启远阅读；现有书架、进度、笔记、设置和已下载的模型保留。`SHA256SUMS.txt` 用于校验安装包。

如需使用普通版提速：先停止朗读，打开 **设置 → 朗读与悬浮 → 免费离线音色包 → 模型版本**，选择 **普通版 · 350MB**，再下载或手动导入对应模型。原 INT8 模型约132MB，继续保留且可以切回；切换后仍使用原音色。普通版模型独立于主安装包，不是必须下载，安装后合成、试听和朗读使用本地文件。

本轮源码通过 **251项 Python 测试、52项前端测试**。在本机以2线程运行正式服务，21句唯一文本全部从冷缓存生成，音频共 **206.175秒**，加权生成耗时为音频时长的 **0.856倍**，启动后无超过300毫秒的句间等待；首句冷启动等待 **13.829秒**。相同文本的缓存回放未再次合成。

上述验证按WAV时长静默消费音频，没有打开扬声器，不能代替 MCI 播放或人工听感验证。不同电脑和文本的生成速度可能不同，性能不足时仍会显示等待并保持所选音色。
