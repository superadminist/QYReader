# QYReader v2.1.5

- 新增 MD/Markdown、DOC 文档阅读，补齐 DOCX 表格文字提取。
- 网页链接可提取文章正文并保存本地副本，支持离线阅读、朗读、搜索和记录进度。副本位于应用数据目录的 `webpages` 文件夹。
- 优化内容库滚动、阅读页切换、长目录及封面悬停动画：恢复默认硬件加速，减少重复渲染，阅读进度改为后台合并保存，大内容库和目录按可见范围加载。
- 内容导入入口依次调整为「导入文件 → 粘贴文本 → 网页链接 → 播客 / 音频」。
- 联网语音增加请求节流、失败退避与诊断日志，减少重复请求。

下载 `QYReader-Setup-2.1.5.exe` 安装或覆盖升级。安装前请先完全退出正在运行的启远阅读；现有书架、阅读进度和设置保留。`SHA256SUMS.txt` 用于校验安装包。

本机真实 Qt 测试中，内容库悬停动画的 P95 帧间隔由 83.3ms 降至 16.8ms；内容库、正文和目录滚动的 P95 帧间隔约为 16.8ms。已完成 1000 本内容库、5000 章目录、窗口圆角及主窗/悬浮朗读同步检查，通过 198 项 Python 测试、46 项前端测试和生产构建。性能数值来自本机测试，不代表所有设备表现；本轮未进行人工听音验收。

网页正文提取适用于可直接获取的 HTTP/HTTPS 页面，不读取浏览器登录状态或执行网页脚本；需登录或动态加载的页面可复制正文后使用「粘贴文本」。DOC 支持未加密的 Word 97–2003 文档。播客 / 音频入口暂不可用。
