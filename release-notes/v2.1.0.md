# QYReader v2.1.0

本版新增正文任意位置开始朗读：在正文中单击，或拖选一段文字，界面会标记朗读起点；点击播放后从该字符位置开始朗读，不再强制回到章节开头或历史进度。

暂停后重新选择位置，再次点击播放同样会从新位置开始。主窗口和悬浮朗读窗继续共享同一个播放控制器与播放状态，不会创建第二套 TTS 状态。

验证覆盖 Unicode 字符偏移、Bridge 契约、播放控制器任意偏移起读、前端构建和 Python/JavaScript 测试。真实 SAPI 语音与扬声器同步仍需在实际 Windows 音频环境验收。

下载 `QYReader-Setup-2.1.0.exe` 安装或覆盖升级。安装前请先完全退出正在运行的启远阅读。
