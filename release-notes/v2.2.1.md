# QYReader v2.2.1

2026-10-28

- **滚轮连续过渡**：主窗口在首次加载页面前开启原生平滑滚动，减少鼠标滚轮整格跳动的感觉。
- **减少滚动中的动画开销**：滚动时暂时停止封面上浮、阴影和继续阅读提示等悬停装饰，停止滚动后恢复；卡片点击与键盘焦点操作继续可用。
- **大书库减少重复工作**：复用布局尺寸，按行批次更新显示范围，避免每次滚动都重新测量卡片；修复无关界面更新导致书架重复渲染的问题。
- **修复筛选边界**：列表缩短、筛选为空或窗口列数变化时，保持有效的显示范围。

本版保留此前用于减少透明窗口闪白的兼容渲染默认值。原生 Qt 桌面实测仍有长帧，尚未达到全程零掉帧；加速模式未取得有效的画面验收证据，因此没有作为默认配置发布。详细方法与限制见仓库的 `docs/scroll-performance-2026-10-28.md`。

验证：77 项前端测试与 31 项 Qt／打包相关 Python 测试通过；本地生产构建及包内程序的启动、版本显示、滚动、菜单和正常退出检查通过。这些检查不等于安装向导、覆盖升级或真实扬声器听感已验收。
