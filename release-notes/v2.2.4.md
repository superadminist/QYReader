# QYReader v2.2.4

2026-11-17

- **默认硬件加速渲染**：书库滚动与书封悬停恢复流畅（帧时间由软件合成的约 83ms 降至约 16ms），可回退软件合成。
- **修复滚动闪白**：主窗口改为不透明渲染，消除硬件加速下滚动时整窗闪白的问题（此前透明窗口 + 硬件加速会因 QtWebEngine 合成交接而丢失整帧）。
- **书库滚动优化**：虚拟窗口阈值下调、移除悬停动画的门控属性，减少滚动时的整网格样式重算。
- **启动提速**：Edge 在线语音改为首次合成时才加载，热启动更快。
- **并发写入加固**：修复导入/阅读进度保存时偶发的 Windows 文件锁冲突。

升级保留既有书架、阅读进度、书签、笔记、设置与已下载模型；渲染模式可在设置中切换（默认硬件加速，硬件环境异常时可回退软件合成），切换后重启生效。

下载 `QYReader-Setup-2.2.4.exe`，使用本 Release 的 `SHA256SUMS.txt` 核对文件。升级前完全退出启远阅读；既有书架、进度、笔记、设置和已下载模型继续保留。
