# Qt 阅读器性能验证（2026-10-02）

首轮优化保留现有界面、软件合成圆角和唯一的 SpeechController / PlaybackService。后续动画优化改用 Qt 默认加速选择，保留原抗锯齿圆角；最新结果见 [动画与合成验证](animation-performance-2026-10-02.md)。下方首轮性能对比保持原始记录。

## 实际改动

- 章节目录按可见行渲染，5000 章不再同时创建 5000 个按钮；保留 Home / End、方向键和章节跳转。
- 阅读进度在内存中立即更新，后台合并同一本书的更新，每 5 秒保存最新位置。暂停、停止、朗读完成立即触发后台保存；换书、关闭会话和退出等待补保存完成。写盘失败会报告并保留最新位置以便重试。
- 书库与播放更新分离，播放状态变化不再重新渲染整页书卡；仅自定义排序进行卡片布局测量。超过 512 本的最近阅读书库按多屏缓冲、分批更新可见行，自定义排序保持原来的拖动行为。
- 正文分块缓存 Unicode 字符数组；选择起点只更新相关正文块。一个播放事件批次只刷新一次悬浮状态。

## 前后对比

环境：当前 Windows 主机、真实 Qt WebEngine 软件合成宿主，通过独立临时数据目录启动 run.bat。相同 300 本书、5000 章、第一章约 2.5 万字；鼠标滚轮连续 40 次，每次 120 像素，间隔 30 ms；重复打开阅读页 5 次。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 打开阅读页中位耗时 | 1354.28 ms | 474.75 ms |
| 目录同时挂载按钮 | 5000 | 16 |
| 目录滚动 TaskDuration | 1206.74 ms | 386.64 ms |
| 目录滚动超过 50 ms 的帧 | 2 | 0 |
| 正文滚动 P95 帧间隔 | 16.70 ms | 16.80 ms |
| 常规书库滚动 P95 帧间隔 | 33.30 ms | 33.30 ms |
| 常规书库滚动超过 50 ms 的帧 | 4 | 2 |
| 100 次阅读进度更新的调用线程耗时 | 3005.89 ms | 1.75 ms |

进度更新的优化后耗时为内存更新与排队耗时，磁盘保存由后台线程合并执行；不代表磁盘写入本身缩短到 1.75 ms。上述改善也不代表所有书籍、所有机器或整个程序都提升相同比例。

## 回归验证

- Python unittest：198 项通过；后台写入合并、慢磁盘时更新不阻塞、连续更新时定期保存、失败重试、换书补保存、中文和 emoji 偏移恢复，以及移除当前书籍后正常退出均覆盖。
- 前端与 Sites：46 项通过；前端生产构建成功。
- 真实本地 SAPI：暂停/恢复及悬浮窗连续 12 次播放按钮切换通过，主界面与悬浮高亮一致。此项是回调和界面验证，未进行人工听音验收。
- 1000 本书、5000 章：滚动到书库末尾、搜索、目录 Home / End、打开最后一章、最近阅读与自定义排序切换均通过。大书库初始书卡挂载 64 个。
- MD、DOC、DOCX、网页提取与自动打开、网页 HTTP 404 不增加空书籍：真实源码 UI 回归通过。
- 首轮的最终 QYReader.exe 打包版：相同 300 本书、5000 章测试，打开阅读页中位耗时 567.07 ms，目录滚动 TaskDuration 425.38 ms、P95 帧间隔 16.80 ms、无超过 50 ms 的帧；常规书库滚动 P95 为 33.30 ms。当前书籍仍有待保存进度时移除成功，正常退出返回码为 0，无前端异常。
