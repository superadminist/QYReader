# 内容库动画与 Qt 合成验证（2026-10-02）

## 改动与原因

- 导入入口按用户标注顺序排列：导入文件 → 粘贴文本 → 网页链接 → 播客 / 音频。
- 原 Windows 配置强制 `QT_QUICK_BACKEND=software` 和 `--disable-gpu`。实际对比表明，单独缓存封面和移除逐帧阴影计算仍无法让软件合成稳定流畅。因此默认交由 Qt 选择硬件加速，显式设置 `QYREADER_RENDER_MODE=software` 时仍保留两层软件合成的兼容方式；不修改系统环境变量或显卡设置。
- 卡片阴影拆成两个固定阴影层，用透明度交替显示，封面和阴影同步上浮 4px；导入入口上浮 2px。悬停过程中不再插值计算模糊阴影。
- 最终只缓存可见封面的 transform 图层：连续滚动期间不改变图层，滚动停止 180ms 后统一更新；阴影和小按钮交由 Chromium 管理。顶部保留 4 张封面、底部 8 张。曾测试滚动中立即预热封面、阴影、按钮的方案，造成回退，已撤掉。指针移动不触发 React 整个内容库更新。
- 显式限定按钮、继续阅读提示的 transition 属性；保留禁用入口、拖动排序和减少动态效果的系统偏好。
- 圆角仍使用既有 CSS 和原生 alpha guard；没有给主窗或悬浮窗安装二值窗口区域。

## 最终打包程序对比

Windows 10、125% DPI、相同 300 本书和 5000 章临时内容库，通过 CDP 原生鼠标事件依次进入、离开前四张书卡，每次等待 240ms，共 12 次进入与 12 次离开。软件模式数值来自前一轮的同 exe 对照（当时缓存策略不同）；默认加速数值来自最终静止封面缓存版本。未开启 Chromium tracing，以免测量增加绘制负担。

| 指标 | 原动画 + 软件合成（前轮对照） | 新动画 + 默认加速（最终版） |
| --- | ---: | ---: |
| P50 requestAnimationFrame 帧间隔 | 33.4 ms | 16.7 ms |
| P95 requestAnimationFrame 帧间隔 | 83.3 ms | 16.8 ms |
| 超过 25ms 的帧 | 128 | 3 |
| 超过 50ms 的帧 | 43 | 1 |

控制对比：同一软件模式下，新动画仍为 83.3ms P95；同一加速模式下，原动画也可达到 16.8ms P95。这表明主要瓶颈是强制软件合成，阴影和缓存优化属于减少绘制负担的补充。该结果是本机测试帧间隔，不代表所有显卡、显示器、机器上的显示帧率承诺。

结果文件位于本次聊天验证目录中的 `performance-hover-package-software.json` 和 `performance-hover-package-idle-cover.json`；截图为 `hover-hover-package-idle-cover.png`。入口顺序、封面与阴影位移一致、三个可用导入入口上浮、禁用播客入口保持静止、滚动到底部后仅缓存可见封面、无前端异常均通过。

## 最终滚动验证

使用最终 exe、300 本内容和 5000 章，连续 40 次原生鼠标滚轮，每次 120px、间隔 30ms，并继续记录停止后的 350ms：内容库 P95 为 16.8ms，正文和目录 P95 均为 16.8ms；内容库有 2 帧超过 50ms，正文和目录均没有。目录挂载 16 个按钮，重复打开阅读页中位耗时 400.81ms。有待保存进度时移除当前内容后正常退出，返回码 0，无前端异常。结果文件：`performance-accelerated-final-idle-cover.json`。

撤回的预热方案：同样滚动测试的内容库 P95 为 66.7ms，LayoutDuration 525.31ms；最终方案连同停止后的封面缓存更新，LayoutDuration 为 68.28ms、P95 仍为 16.8ms。此项回退已解决，未交付滚动中完整图层预热方案。完全不缓存封面虽也达 16.8ms P95，但 12 次悬停出现 11 个超过 50ms 的帧；最终静止封面缓存将其降为 1 个。

## 回归与边界

- 最终 exe 的 1000 本内容库：滚动到底部、搜索、最近阅读/自定义排序切换、目录 Home/End/末章、移除有待保存进度的内容和正常退出全部通过，无前端异常；虚拟书库初始挂载 64 张卡片。结果：`performance-accelerated-final-large.json`。
- Python unittest：198 项通过；前端与 Sites：46 项通过；Vite 生产构建、PyInstaller、Inno Setup 均完成。
- 独立原生圆角测试：主窗和悬浮窗各四种尺寸，透明角像素与抗锯齿像素均通过；最大化角像素不透明。
- 实际 DesktopWindow：四种尺寸缩放、最大化/还原、全屏/退出、悬浮窗三种尺寸和移动、主窗隐藏后恢复，12 个检查全部通过。主窗正常圆角、最大化/全屏方角、悬浮圆角和透明边缘正确；截图已检查。此项用实际窗口几何变化验证，不等同于人工鼠标持续拖动的听音验收。
- 真实 SAPI：150 语速的完整流跟踪通过，12 次悬浮播放按钮切换、主窗/悬浮句子匹配、第三句推进、真实流编号和首词回调对应正确。首次 200 语速快速验收在悬浮窗打开的句子边界报告一次文字变化；复查采用流跟踪核对实际音频开始事件，未更改播放实现。未做人工听音验收。
- 旧 stage4 全量驱动未完成：该驱动额外强制生产不存在的 `--single-process` 并对 `.book-card` 而非内部阅读按钮执行点击，停在阅读页打开检查。此项不记为通过；上面的专门窗口验收和 SAPI 验收使用实际默认多进程路径。
