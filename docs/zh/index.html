开始之前

你可能想了解

关于阅读、听书，和你的本地书库。

支持哪些系统和文件格式？

启远阅读面向 Windows 10 / 11。支持 TXT、Markdown、Word（DOC / DOCX）、EPUB、MOBI、AZW3、PDF、HTML 和 ZIP，也可以粘贴文本，或从公开网页提取正文保存到本地。

不联网，也可以听书吗？

可以。下载或导入 Kokoro 离线音色包后，即可在本机合成与播放；也可以使用 Windows 系统语音。Edge 在线音色需要联网，会将相应朗读文本发送给语音服务。Kokoro 模型独立下载，实际合成速度取决于电脑配置。

悬浮窗和主窗口的进度会同步吗？

会。两者共享同一份阅读进度与播放状态。主窗口最小化后，悬浮窗仍可使用；也可以一键返回主窗口。纯正文模式会在鼠标移开后隐藏标题栏与播放控件。

书籍、笔记和进度保存在哪里？

默认保存在本机，无需注册账号。书架、阅读进度和笔记不会上传。可以在设置中的“备份与恢复”保存完整快照；使用 Edge 在线语音时，相应文本会发送给该服务。

桌面软件有英文界面吗？

当前桌面界面为简体中文，内置 Kokoro 离线音色包提供中文音色。官网与英文 README 提供英文产品介绍。页面图片为 UI 设计展示，以实际版本为准。
